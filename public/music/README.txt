PUT YOUR MUSIC HERE (optional)
------------------------------
Copy an .mp3 into this folder and set, in src/config.js:

  music: { src: 'music/our-song.mp3', ... }

Keep the file small (under ~4 MB, 128 kbps is plenty) and make sure you have
the right to use it. Music never autoplays: she chooses with the button
in the top-right corner. If src is left empty, the button is hidden.
